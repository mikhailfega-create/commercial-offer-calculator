# Калькулятор коммерческих предложений

Статическое браузерное приложение для расчёта стоимости заказа и формирования готового текста коммерческого предложения.

## Возможности

- расчёт позиций по формуле «количество × цена»;
- готовый русский текст коммерческого предложения;
- копирование, скачивание .txt и печать в PDF;
- автосохранение черновика и локальная история;
- работа на компьютере и телефоне;
- отсутствие backend, регистрации, базы данных и внешних API.

## Запуск

Открой index.html в браузере. Установка и сборка не нужны.

Все пользовательские данные хранятся только в localStorage текущего браузера.
